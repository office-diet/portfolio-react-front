# 🎨 フロントエンド設計・仕様書 (Frontend Specs)

本アプリケーション（Realtime Anonymous Chat App）のフロントエンド（React / Vite / TypeScript / Chakra UI）における設計方針、コンポーネント構成、およびUI/UXのこだわりについて記載します。

---

## 1. 技術スタック
* **フレームワーク:** React (v18+)
* **ビルドツール:** Vite
* **言語:** TypeScript
* **UIライブラリ:** Chakra UI

---

## 2. ディレクトリ・コンポーネント構成

アプリケーションのUIは、単一責任の原則に基づき適切にコンポーネント分割されています。

* `src/App.tsx`
  * **役割:** アプリケーションの根幹。WebSocketの接続管理（`useEffect`）、サーバーからの受信メッセージの一元管理、および全体レイアウト（ヘッダー、履歴、入力欄）の統括。
* `src/History.tsx`
  * **役割:** チャットのメッセージ履歴を表示するコンポーネント。送信者（自分、臼ちゃん、さやか、その他の参加者）に応じた動的なスタイル（背景色やアライメント）の切り替えと、スマートな自動スクロール制御を実装。
* `src/InputArea.tsx`
  * **役割:** メッセージ入力エリアおよび送信ボタン。日本語入力時の変換確定（`isComposing`）を考慮した Enter キー送信制御を実装。
* `src/Types.tsx`
  * **役割:** クライアント・サーバー間でやり取りされるWebSocketメッセージおよびデータ構造の型定義を集約。

---

## 3. 主要な実装のこだわり・技術的ハイライト

### ① 堅牢なWebSocketライフサイクル管理 (`App.tsx`)
* 初回マウント時に `WebSocket` を確立し、接続時にクライアント環境情報（`JoinInfo`）を自動送信。
* アンマウント時にはステータスを確認して確実にソケットをクローズし、メモリリークや意図しない多重接続を防止。
* 受信したメッセージの型（`type: "online" | "visitorId" | "chat"`）に応じて状態を安全に分岐・更新。

### ② ユーザー体験（UX）を考慮した自動スクロール制御 (`History.tsx`)
* ユーザーが過去のログを遡って読んでいる最中に新しいメッセージが届いても、強制的に最下部にスクロールさせないよう判定ロジックを実装。
* 一番下にいる（または初回ロード時）の視点にいる場合のみ、`scrollIntoView({ behavior: "smooth" })` でスムーズに最新メッセージへ追従。

### ③ クライアント環境の自動検出 (`App.tsx` / `getJoinInfo`)
* `navigator.userAgent` や `navigator.userAgentData` を解析し、OS（Windows, macOS, iOS, Android等）、デバイス種別（PC/mobile）、ブラウザ、タイムゾーンを自動取得してセッション情報として活用。

### ④ 入力ストレスのないキーボード操作 (`InputArea.tsx`)
* `Enter` キーによるクイック送信に対応しつつ、日本語入力時の変換確定による誤送信を防ぐため `!e.nativeEvent.isComposing` のガード処理を実装。
* `Shift + Enter` による改行を許容し、チャットツールとして自然な使い心地を実現。
